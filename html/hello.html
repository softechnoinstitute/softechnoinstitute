Excel String Functions

String (text) functions in Excel help you clean, split, combine, format, and analyze text data such as names, emails, product codes, and addresses.

Theory

  • Text extraction: Get specific characters from left, right, or middle positions.
  • Text cleaning: Remove extra spaces or non-printable characters.
  • Text joining: Merge words, names, or IDs into one formatted string.
  • Case conversion: Convert text into upper, lower, or proper case.
  • Search and replace: Find and replace characters/words in text.

Syntax and Practicals

1) LEFT

Syntax: =LEFT(text, [num_chars])

Practical: If A2 = "SOFTECH123", then =LEFT(A2,7) returns "SOFTECH".

2) RIGHT

Syntax: =RIGHT(text, [num_chars])

Practical: If A2 = "SOFTECH123", then =RIGHT(A2,3) returns "123".

3) MID

Syntax: =MID(text, start_num, num_chars)

Practical: If A2 = "STI-2026-AGRA", then =MID(A2,5,4) returns "2026".

4) LEN

Syntax: =LEN(text)

Practical: If A2 = "Agra Center", then =LEN(A2) returns 11.

5) TRIM

Syntax: =TRIM(text)

Practical: If A2 has extra spaces like " Rahul Kumar ", =TRIM(A2) returns "Rahul Kumar".

6) UPPER / LOWER / PROPER

Syntax: =UPPER(text), =LOWER(text), =PROPER(text)

Practical: If A2 = "rAhUl kuMaR", then:

  • =UPPER(A2) → "RAHUL KUMAR"
  • =LOWER(A2) → "rahul kumar"
  • =PROPER(A2) → "Rahul Kumar"

7) CONCAT / TEXTJOIN

Syntax: =CONCAT(text1, text2, ...), =TEXTJOIN(delimiter, ignore_empty, text1, ...)

Practical: If A2 = "Rahul", B2 = "Kumar":

  • =CONCAT(A2," ",B2) → "Rahul Kumar"
  • =TEXTJOIN("-",TRUE,A2,B2) → "Rahul-Kumar"

8) FIND / SEARCH

Syntax: =FIND(find_text, within_text, [start_num]), =SEARCH(find_text, within_text, [start_num])

Practical: If A2 = "info@softech.com":

  • =FIND("@",A2) returns the position of "@".
  • =LEFT(A2,FIND("@",A2)-1) extracts the username "info".

9) SUBSTITUTE / REPLACE

Syntax: =SUBSTITUTE(text, old_text, new_text, [instance_num]), =REPLACE(old_text, start_num, num_chars, new_text)

Practical: If A2 = "Batch-2025":

  • =SUBSTITUTE(A2,"2025","2026") → "Batch-2026"
  • =REPLACE(A2,7,4,"2026") → "Batch-2026"

Combined Practical Example

Goal: Convert email in A2 (e.g., "rahul.kumar@sti.com") into a clean name.

Formula: =PROPER(SUBSTITUTE(LEFT(A2,FIND("@",A2)-1),"."," "))

Output: "Rahul Kumar"
